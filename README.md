# Pixeltor

Editor de pixel art para Windows y Linux con **capas inteligentes**: ráster pintable, formas vectoriales que se rasterizan pixel-perfect en vivo y efectos no destructivos. Admite varias imágenes por archivo con animación y visores divididos.

**🌐 [Página web y documentación](https://sanchezmendozajean.github.io/pixeltor/)** · **⬇️ [Descargas](https://github.com/sanchezmendozajean/pixeltor/releases)**

## Desarrollo

```
npm install
npm run dev
```

Más comandos: `npm run lint`, `npm run typecheck`, `npm test`, `npm run pack:win`, `npm run pack:linux`. Las especificaciones están en [`specs/`](specs/README.md) y los cambios en el [CHANGELOG](CHANGELOG.md).
